# Application A002: service and experiment contracts

Status: implementation record, 2026-10-01. Classification: **A2-READY**. Targeted tests: 11 passed. Full suite: 267 passed, one existing opt-in full-graph test skipped. Compile, tracked integrity, diff check, and package build passed. The wheel includes `malecns_sim.application`.

## Boundary and public API

The package is `malecns_sim.application`: `models.py` owns frozen typed contracts and canonical JSON, `events.py` owns lifecycle transitions and event envelopes, `errors.py` owns stable error categories, `service.py` orchestrates registered data and existing engine APIs, and `serialization.py` owns atomic JSON manifest writes and checked reads. Public entrypoints are `ExperimentSpec.from_dict`, `validate_experiment`, `run_experiment`, `write_result`, and `read_result`. `DatasetFiles` is a trusted local registration supplied by the future A003 server, never a frontend supplied path. A002 starts no HTTP listener.

`ExperimentSpec` is `application-experiment-v1`; unknown fields are rejected on decoding. It contains exact dataset hashes and curated graph fingerprint, explicit uint32 trial seeds, bounded duration and trial count, frozen sugar members/fingerprint/side, 10/25/50/100/150/200 Hz input selection, Poisson timing and weight factor, side resolved MN9 target, baseline or one outgoing-silence ID, all LIF parameters and fingerprint, sign/resolution policy IDs, selected traces, and an explicit robustness request type. The service rejects robustness execution until A007. The supported model weight is exactly 0.275 mV because `prepare_network` fixes the effective projection at that value. Sign IDs are verified after preparation. The model's other LIF values are passed to `simulate_lif`/`simulate_cuda` without reinterpretation.

Canonical bytes are sorted-key compact UTF-8 JSON, finite numbers only, with integral floats normalized to JSON integers. SHA-256 of those bytes is the spec digest. Run ID is domain-prefixed SHA-256 over spec digest, dataset identity, package version, model/sign identities, explicit seeds, realized schedule fingerprints, selected backend, curated graph fingerprint, and result schema. No timestamp, hostname, or absolute path enters either identity. Git commit/dirty status are optional result provenance. Installed packages without Git remain executable. The run ID uses the declared curated graph fingerprint before loading, which is checked against the prepared graph; effective signed projection fingerprint is additional provenance. Invocation UUID distinguishes repeated executions.

The service checks registered file SHA-256 values, the frozen sugar predicate through existing Task 008 identity preparation, population fingerprint/member IDs, MN9 laterality, graph membership, projection fingerprint, sign/resolution IDs, and GPU availability. It calls `prepare_network` with no cache path, then `simulate_lif` on CPU or lazy-imported `simulate_cuda` on CUDA. It uses engine `PoissonStimulus.generate` for the active interval and passes its shifted explicit schedule to the engine. It never calls historical Task 010/011/017/018 runners. CPU import does not import CuPy. No Task 017 matrix or Task 017Q work is executed.

## Results, playback, and integrity

`ExperimentResult` is `application-result-v1`. Each completed trial carries engine spike digest, target count/rate and exact target spike timesteps, canonical sparse `(timestep, neuron ID)` events, at most 16 selected v/g traces, and optional engine delivery samples. Inline spikes are capped at one million events; future large runs need separately hashed binary payloads. `PopulationBins` is explicitly visualization data and is never included in the authoritative digest. The authoritative digest is domain-prefixed SHA-256 over executed spec, run identity, backend, resolved stimulus/intervention summaries, trials, and optional comparison/robustness records. Volatile timestamps, Git metadata, warnings, and visualization bins are excluded. A second manifest digest covers the whole JSON object except itself. `write_result` uses a temporary file, flush/fsync, and atomic replace; it returns the final file SHA-256. `read_result` checks an expected file hash and internal digests. Failure/cancellation errors carry a versioned partial result with terminal status, structured error, and exactly the completed trials. A003 must keep paths inside its controlled result root and expose references rather than arbitrary local paths.

`Comparison.create` computes baseline, intervention, absolute delta, and relative delta. A zero baseline produces `null` and `ZERO_BASELINE`; no biological score is defined. `RobustnessRequest` records explicit variants, parameter overrides, seeds, and optional aggregate rule ID; `RobustnessResult` records backend results. A002 computes no robustness aggregate or scientific verdict. A frontend may display a backend aggregate but may not create one.

## Lifecycle and error contract

States are CREATED, VALIDATING, LOADING_DATA, PREPARING_NETWORK, RUNNING, FINALIZING, COMPLETED, FAILED, and CANCELLED. Active states advance in order or terminate; terminal states never transition. Events have schema version, run/invocation IDs, monotonic sequence, UTC timestamp, phase, type, visualization flag, and JSON payload. Lifecycle events are RunStarted, PhaseChanged, TrialStarted, TrialCompleted, RunCompleted, RunFailed, RunCancelled, and Warning. Optional replay/preview events are explicitly visualization only. Only completed/total trials are emitted as measurable progress; no simulation percentage is fabricated.

Stable errors are INVALID_SPEC, UNSUPPORTED_OPERATION, UNSUPPORTED_BACKEND, GPU_UNAVAILABLE, DATASET_PROVENANCE, PREPARATION_FAILED, SIMULATION_FAILED, CANCELLED, and RESULT_SERIALIZATION. Exceptions retain Python causes locally; the public shape is code/message/phase. `EventJournal` is a durable JSONL sink that validates sequence and fsyncs each event; the caller controls the path and may combine it with a UI sink. Cancellation is cooperative before and after each opaque trial engine call. There is no mid-trial CPU callback or mid-kernel CUDA cancellation claim. CANCELLED is emitted only when a boundary actually observes a request.
