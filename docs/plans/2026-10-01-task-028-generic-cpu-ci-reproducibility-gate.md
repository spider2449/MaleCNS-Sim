## Offline integrity design

`scripts/check_tracked_integrity.py` reads and SHA-256 checks the Task 017 complete-matrix, recovery, and scoring JSON; Task 018 execution JSON; MaleCNS and Shiu provenance manifests; Task 008A's preservation manifest and tracked Task 008 result; and Task 018 preregistration. Git's LF-normalized text is used for stable clone identity across checkout settings. Task 018's raw-manifest reference and Task 008A's preserved result reference are historical Windows CRLF digests, which are checked against the corresponding CRLF encoding derived from the pinned LF bytes. It checks Task 017 matrix/recovery/scoring cross references, completion and schema, scoring's deterministic digest, Task 018's stored result digest and manifest/preregistration references, Task 008's preservation relationship, and external file digest syntax. The Task 017 bundle, journal, sidecars, and MaleCNS/Shiu raw bytes are intentionally absent and are not opened. The checker performs no simulation, scientific endpoint calculation, network request, or write. `tests/test_tracked_integrity.py` copies the protected inputs to a temporary directory, verifies success, corrupts the recovery checkpoint fingerprint, verifies failure, then re-pins the corrupt file hash and verifies cross-reference failure. Canonical tracked artifacts are never modified by the test.
