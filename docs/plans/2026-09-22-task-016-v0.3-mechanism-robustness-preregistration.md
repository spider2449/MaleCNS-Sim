# Task 016 - v0.3 Mechanism-Robustness Preregistration

Status: PREREGISTERED DESIGN ONLY on 2026-09-22. This document freezes the
v0.3 robustness study and its execution gate. Task 016 does not implement a
model variant, run a simulation, inspect a robustness output, tune a variant,
or discover a candidate neuron.

All code descriptions and any future implementation comments associated with
this plan must be in English. The exact authorization boundary for Task 017 is
in Section 20.

## 1. Research question

The primary question is:

> Do the qualitative Task 010 causal-effect conclusions and Task 011
> temporal-mechanism classifications remain stable under independently
> justified alternative model assumptions?

This is a robustness question about model-level conclusions. It does not ask
whether every firing-rate number remains identical. The graph, neuron
identities, stimulus populations, trial schedules, intervention identities,
Task 010 thresholds, and Task 011 logic are held fixed while a small
predeclared model matrix is evaluated.

## 2. Hypotheses

- H1, robustness: most frozen Task 010 effect directions and coarse effect
  categories, and most frozen Task 011 classifications, remain stable across
  the declared non-reference matrices.
- H2, model dependence: at least one declared model assumption changes an
  effect direction, coarse category, or mechanism classification in a way that
  is not explained by the preregistered partial-compatibility rule.
- H3, ambiguity-localized dependence: changes are concentrated in the
  reference `MIXED` or `UNRESOLVED` cases rather than overturning the clearly
  classified network-compatible cases.

These hypotheses are alternatives. No probability, preferred result, or
post-result model selection is specified.

### 7.1 Rationale and support for each member

`R0_REFERENCE_TASK005` is required as the matrix anchor. It is the accepted
Task 005 formulation and is not an alternative or a result-selected control.

`V1_TAU_MEMBRANE_FAST` and `V2_TAU_MEMBRANE_SLOW` test the explicitly
parameterized membrane integration timescale on both sides of the reference.
The independent basis is the Task 005 equation and validation suite, which
defines `tau_membrane` as a model parameter and validates the general
analytical update rather than a fitted MaleCNS value. Ten and thirty ms are
predeclared 50% endpoint alternatives around 20 ms, chosen as a bounded
sensitivity pair, not estimated from Task 010/011 outputs. Expected numerical
implication: the membrane state integrates input over a shorter or longer
window; no direction of MN9 effect is predicted.

`V3_TAU_SYNAPSE_FAST` tests a shorter conductance-decay assumption at
`2.5 ms`, a predeclared 50% endpoint around the reference `5.0 ms`. Its basis
is the Task 005 one-state synaptic equation and its independently tested
analytical time-constant handling. Expected numerical implication: each
synaptic conductance contribution decays faster; recurrent rate and effect
direction are not predicted.

`V4_DELAY_SHORT` tests a one-millisecond transmission latency. The value is
exactly representable at the frozen `0.1 ms` clock and is an independently
specified short-delay alternative to the reference `1.8 ms`. Its basis is the
Task 005 exact-delay scheduling semantics and the explicit fact that delay is
a declared model parameter. Expected numerical implication: delivered events
move from 18 to 10 timestep boundaries; no endpoint direction is predicted.

`V5_WEIGHT_LOW` tests `0.200 mV` per anatomical synapse. The value is a fixed
pre-execution reduction of the Task 005 uniform synaptic-weight assumption.
Its basis is the Task 005 source semantics in which anatomical synapse counts
are multiplied by one declared scalar, plus the existing parameter-identity
validation. The same scalar is used for graph events and the fixed-factor
direct sugar input. Expected numerical implication: each signed anatomical
event and each direct input event has lower amplitude; no MN9 category is
presumed.

`V6_THRESHOLD_HIGHER` tests `v_threshold=-44.0 mV` while retaining the
reference rest/reset voltages and strict `v > threshold` rule. Its basis is the
Task 005 explicit threshold/reset semantics and a fixed one-millivolt
excitability perturbation, specified before any v0.3 result. Expected numerical
implication: a larger depolarization is required to emit a spike; the network
response is not assumed to decrease monotonically because recurrent inhibition
and disinhibition can change the intervention contrast.

`V7_CONSERVATIVE_SIGNS` uses the existing `ConservativeSignPolicy`, which
assigns only acetylcholine to `+1` and GABA to `-1`; dopamine, octopamine,
serotonin, histamine, unsupported labels, and missing identities remain
unresolved. Its basis is the already implemented alternative policy and the
Task 004 rule that unresolved signs are not silently assigned zero, excitation,
or inhibition. The unsigned anatomical graph and all identities remain fixed;
only the effective signed projection and its fingerprint may change. Expected
numerical implication: signed-edge coverage can decrease relative to the Shiu
policy; no endpoint direction or classification is predicted.

No variant is optimized for a reference rate, effect sign, category, temporal
label, Shiu reproduction score, or any other MaleCNS output. No variant is
added if its result is scientifically inconvenient.

## 8. Level A - causal-effect robustness

For every candidate, side, and matrix member, run a same-matrix baseline and a
same-matrix outgoing-silencing intervention. The intervention remains the
Task 010 intervention: suppress outgoing synaptic-event scheduling from the
selected candidate while retaining its input, state updates, and internal
spikes.

For `MN9_L` and, secondarily, `MN9_R`, record:

- baseline mean rate in Hz;
- silenced mean rate in Hz;
- signed change `silenced - baseline`;
- absolute change `abs(silenced - baseline)`;
- percentage change `100 * signed_change / abs(baseline)` when baseline is
  nonzero, otherwise null;
- effect sign; and
- Task 010 category `major`, `moderate`, `small`, or `negligible`.

The primary Level A features are effect direction and coarse category, not
exact Hz equality. Trial-level paired deltas, aggregate means, and canonical
spike digests are retained for audit but are not used to redefine categories.

## 10. Level C - global conclusion robustness

The v0.2 conclusion under test is:

> Anatomical prominence and short-path structure do not consistently predict
> perturbational influence on MN9_L, and the strongest counterintuitive
> perturbation effects are predominantly compatible with recurrent/network
> redistribution, with short-path contributions in some candidate/stimulus
> conditions.

The first clause is tested only through the frozen effect direction/category
matrix; topology and candidate selection are not re-ranked. For the second
clause, the reference-defined counterintuitive set is fixed as `10313` and
`10135` under both LEFT and RIGHT conditions. The reference-defined
network-compatible set is `NETWORK_REDISTRIBUTION_COMPATIBLE` or `MIXED`. The
reference-defined short-path-contribution set is the three `MIXED` cells:
`10135/RIGHT`, `12752/LEFT`, and `12752/RIGHT`.

A single non-reference variant is called global-conclusion-supporting when:

1. at least three of the four counterintuitive cells are network-compatible;
2. no more than one of the four reference `NETWORK_REDISTRIBUTION_COMPATIBLE`
   cells changes directly to `SHORT_PATH_COMPATIBLE`; and
3. at least two of the three reference `MIXED` cells remain `MIXED` or become
   `SHORT_PATH_COMPATIBLE`.

This rule tests the declared model-level wording. It does not turn a
compatibility label into a biological mechanism claim.

## 11. Quantitative robustness rules

All stability proportions below use the seven non-reference variants `V1`-
`V7` after the execution gates have passed. The reference matrix is not
counted as evidence for its own stability.

### 11.1 `EFFECT_DIRECTION_STABLE`

For each of the ten candidate-by-side cells, a nonzero reference sign is
stable when the corresponding non-reference signed effect has the same strict
sign. A reference zero is stable only when the alternative effect is exactly
zero under the recorded rate arithmetic; values within `1e-12 Hz` of zero are
recorded as `ZERO` for this rule. The cell is `EFFECT_DIRECTION_STABLE` when
at least `6/7` valid non-reference variants agree with the reference sign.

### 11.2 `EFFECT_CATEGORY_STABLE`

Use the fixed ordinal order
`negligible < small < moderate < major`. A variant category is allowable when
its ordinal distance from the reference category is at most one. The cell is
`EFFECT_CATEGORY_STABLE` when at least `6/7` variants are allowable. A
direction reversal can therefore remain a category match; it is still a
direction failure and is reported separately.

### 11.3 `MECHANISM_CLASSIFICATION_STABLE`

For each of the ten cells, compare the alternative label with the frozen
reference label:

- exact match scores `1`;
- `NETWORK_REDISTRIBUTION_COMPATIBLE` versus `MIXED` in either direction is
  a partial match scoring `0.5`;
- `SHORT_PATH_COMPATIBLE` versus `MIXED` in either direction is a partial
  match scoring `0.5`;
- `UNRESOLVED` versus any other label scores `0`; and
- `SHORT_PATH_COMPATIBLE` versus
  `NETWORK_REDISTRIBUTION_COMPATIBLE` scores `0` in either direction.

The last rule ensures that short-path and network-redistribution labels are
never treated as equivalent. A cell is exact-stable at `6/7` exact matches. A
cell is compatible-stable when its seven scores sum to at least `6.0/7` and no
direct short-path/network transition occurs. Partial matches are retained in
the report and do not become exact matches.

### 11.4 `GLOBAL_ROBUSTNESS`

The matrix is `ROBUST` only if all seven non-reference variants are valid, all
of the following hold, and the conclusion-support rule in Section 10 holds
for all seven variants:

- at least `8/10` cells are `EFFECT_DIRECTION_STABLE`;
- at least `8/10` cells are `EFFECT_CATEGORY_STABLE`; and
- at least `8/10` cells are mechanism compatible-stable.

The matrix is `PARTIALLY_ROBUST` when all seven variants are valid, at least
five of seven variants support the global conclusion, and at least `5/10` cells
meet each of the three cell-level stability rules. Otherwise, with all seven
variants valid, it is `NOT_ROBUST`.

The result is `INDETERMINATE` if any required matrix member is technically
excluded, any required metric is undefined for a reason not covered here, or
the execution gate is breached. An incomplete matrix is never silently
reanalyzed with a more favorable denominator.

The corresponding predeclared conclusion decisions are:

| Evidence rule | Conclusion decision |
| --- | --- |
| `ROBUST` criteria | `SUPPORT` the v0.2 conclusion |
| `PARTIALLY_ROBUST` criteria | `PARTIALLY_SUPPORT` the v0.2 conclusion |
| `NOT_ROBUST` criteria | `FAIL_TO_SUPPORT` the v0.2 conclusion |
| `INDETERMINATE` criteria | no global scientific decision; return for review |

## 12. Invalid and pathological variant rules

A variant is excluded from scientific comparison only for an objective
technical failure below. The reason, first failing check, and partial execution
state must be recorded. Scientific inconvenience is never an exclusion reason.

1. The declared parameter cannot be represented exactly on the frozen clock,
   or the implementation silently rounds it.
2. A required state, event count, rate, trace value, or digest is non-finite,
   or any absolute state value exceeds `1,000,000` in its declared mV unit,
   indicating numerical overflow rather than a scientific result.
3. The run does not complete deterministically under the declared finite
   duration and fixed schedule, or repeated execution produces different
   canonical output.
4. The unsigned graph fingerprint, frozen population fingerprint, readout
   identity, candidate identity, schedule fingerprint, or declared variant
   fingerprint is wrong.
5. The CPU correctness gate fails, or a CUDA result fails the exact/equivalence
   requirements in Section 13.
6. A required trace cannot be produced without changing canonical spike
   semantics, or trace instrumentation changes canonical spikes.

Pervasive network silence, high activity, saturation, a zero candidate
   activity exposure, an all-zero effect, and an `UNRESOLVED` classification
   are not technical exclusions by themselves. They are scientific outputs
   and remain in the denominator if the numerical and reproducibility gates
   pass. If a trace is undefined because no evidence exists, the frozen Task
   011 logic records `UNRESOLVED`; it does not trigger a new label.

## 13. Reference reproduction and CPU/CUDA correctness gates

### 13.1 General reference-model sanity gate

Before any scientific matrix output is inspected, the reference member `R0`
must pass the existing Task 005 synthetic tests and the accepted Shiu v630
context check. The read-only Shiu oracle is the official
`sugarR_100Hz.parquet` result. The hard contextual tolerance is:

- 30-trial MN9 mean rate within `5.0 Hz` of the official `67.0333 Hz`; and
- active-trial fraction within `0.001` of the official `1.0000`.

The previously recorded network-total differences remain contextual and are
reported, not tuned. This is a hard pre-execution gate for the reference
engine, not a criterion used to tune any alternative. It is not a demand that
an alternative parameterization reproduce the published Shiu result.

Every alternative must separately pass the same model-independent synthetic
equation and scheduling sanity tests before it is eligible for MaleCNS
comparison. No alternative is adjusted to pass either gate.

### 13.2 Minimum synthetic equivalence test

For every matrix member, run CPU and CUDA float64 on the same deterministic
fixtures before full-graph output is inspected:

- one isolated neuron with analytic conductance decay and direct input;
- one delayed excitatory/inhibitory chain;
- simultaneous and duplicate-time events; and
- refractory clamping, reset, and delayed delivery.

Require identical canonical spike IDs and timesteps, identical spike-result
digests, and trace-state agreement at `atol=1e-10`, `rtol=1e-12`. Any failure
stops execution.

### 13.3 Minimum full-graph equivalence test

For each matrix member, use the validated full curated Task 008-011 graph and
the exact frozen LEFT trial-0 schedule for candidate `10313`:

- a 20 ms silenced trace run with trace IDs `10313`, `10135`, `12752`,
  `512730`, `43765`, `MN9_L`, and `MN9_R`; and
- a 1000 ms baseline and a 1000 ms `10313` intervention replay.

The CPU and CUDA paths must have exact canonical spike-event equality and the
same spike-result digest. Sparse delivered-event counts, target counts, target
index sums, delivered signed weight sums, and selected-state traces must agree
with the frozen tolerances. A traced and untraced CUDA replay must have the
same canonical spike digest. A mismatch stops execution and cannot be
explained away by rate-category agreement.

CPU remains the correctness oracle. CUDA is an implementation path only. All
state and graph arrays used for scientific comparison are float64 where the
validated backend uses floating-point state. If a variant cannot use the
validated CUDA backend without changing semantics, it may run entirely on CPU
only if that limitation is identified before output inspection and CPU
correctness passes; otherwise it is technically excluded under Section 12.

## 16. Execution stopping rules

Execution must stop and return for review if any of the following occurs:

- a preregistered variant cannot be implemented without changing scientific
  semantics;
- the reference baseline no longer reproduces Task 010/011;
- CPU/CUDA mismatch occurs;
- trace instrumentation changes canonical spikes;
- candidate, stimulus, readout, population, or trial definitions drift;
- a required threshold or compatibility rule is ambiguous;
- implementation requires outcome-dependent tuning;
- any scientific output is accidentally inspected before this execution gate
  is frozen and recorded;
- a tag or release would need modification;
- the computational budget is exceeded before the matrix is complete; or
- an unregistered parameter, candidate, trial, label, or analysis is proposed.

Stopping is fail-closed. It does not authorize dropping a difficult or
scientifically inconvenient variant and recomputing a favorable conclusion.

## 18. Scientific nonclaims

An outcome can support only a model-level statement about stability under the
declared assumptions. `NETWORK_REDISTRIBUTION_COMPATIBLE` means that the
observed trace evidence is compatible with recurrent/network redistribution in
this model; it does not prove a biological circuit or direct inhibition,
disinhibition, necessity, or sufficiency. Structural prominence, anatomical
weight, a two-hop proxy, effective signed weight, firing activity, and
perturbational influence remain distinct quantities.

A robust classification is not biological validation. A partial or failed
robustness result does not identify which alternative is biologically correct.
An unresolved or pathological-looking scientific result is not evidence that
the candidate should be removed.
