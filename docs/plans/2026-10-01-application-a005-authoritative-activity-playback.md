## Time and display semantics

The engine records a spike at loop update `k - 1` as timestep `k`, legal `1..N` where `N=duration/dt`. Displayed event time is exactly `k * dt_ms` (post-update), including 0.1 ms for first and 100.0 ms for final events in the standard run. Cursor 0 ms has no event at timestep zero. The clipped inclusive display window is cursor ±1 ms. Its orange viewport ring and raster cursor are display rules. Orange means at least one recorded spike in that window; it does not mean propagation, causal pathway, transmission or arrival. The colored node role fill and white selected ring remain visible. Edges never carry activity animation.

Raster rows are deterministic: stimulus, context, intervention, target, each ascending body ID. The bounded current A004 viewport supplies rows. The optional derived population chart counts its recorded spikes in selected 1/2/5 ms bins. Bin width does not mutate the result, event timestamps, authoritative digest, or playback digest. Selected-neuron inspection lists exact timesteps and converted milliseconds. Trace view reports unavailable when no selected trace was requested. The stimulus view shows only the configured interval and requested frequency because realized input events are unavailable; it does not generate events from frequency.
