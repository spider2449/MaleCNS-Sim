# 0.4.0 application/runtime candidate notes

**Unreleased candidate; validation pending.** Package version is 0.4.0. These notes describe the
engineering minor-release candidate; no 0.4.0 artifact, tag or publication is
certified. This is separate from earlier unresolved scientific v0.4/BANC work.

## Added since the historical v0.3.0 release

- Stable CPU `malecns_sim.runtime.prepare_runtime` for an existing effective
  signed projection, opaque runtime/state handles and detached immutable
  AdvanceResult records. Prepare once; advance independent fresh states many
  times with delayed/refractory continuity and explicit event schedules.
- Engineered local workbench with experiment validation/status, schematic
  subgraphs, recorded playback, comparison and explicit robustness evidence.
  The fixed synthetic closed-loop Arena is experimental/example-only.
- Optional `malecns_sim.experimental.gpu` facade with explicit resource close;
  retained resumable backend is experimental. No automatic GPU selection.
- Consumer lifecycle/time/error/migration documentation and a separate
  application/runtime artifact gate.

Existing one-shot/root/dynamics exports, scientific equations/defaults, CLI names
and historical results remain unchanged. No mandatory migration. The new API is
opt-in; it does not support raw-state editing, serialization/checkpoint restore,
traces, timing hooks, concurrency, backend migration or arbitrary biological
adapters. See the [runtime guide](../runtime/USER_GUIDE.md).

## Evidence and limitations

[A023-A](../plans/2026-10-07-application-a023-r11-closeout-result.md) accepted
the implementation under release-safe validation: 1544 passing tests, 12 NOT RUN,
I0 unprotected content and bounded I2 PASS. I1 protected integrity remains NOT RUN.
Those results do not certify a new A024/A025 wheel, every supported Python version,
new device execution or a fresh blind operator pass. Historical failed/invalidated
validation and PE3-UNRESOLVED remain preserved.

Historical full-real CPU replay is two fresh 240-ms trajectories, not a continuous
480-ms trajectory. Its measured mean 1.094710500 s per 20-ms call remains slower
than realtime. GPU EQ-B is bounded synthetic correctness; the paired S1-S4 matrix
found CPU faster at all 80 positions on the tested host. GPU performance is paused;
no full-real GPU attempt or speedup is justified. Resources and source prerequisites
are described in the guide; raw data are not bundled.

The workbench is a connectome simulation workbench for virtual intervention
screening and computational hypothesis prioritization. No biological causality,
brain reconstruction, digital twin, behavior prediction, validated biological
sensorimotor coupling or biological realtime claim is introduced. Task017 remains
NOT_ROBUST, Task017Q KEEP_DEFERRED and Task026
NO_V0_4_SCIENTIFIC_QUESTION_CURRENTLY_READY.
